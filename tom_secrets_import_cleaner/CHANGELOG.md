# Changelog

## 0.1.0

- `tsm_import_cleaner`: cleans an Enpass (JSON, CSV), Bitwarden (JSON),
  1Password (1PUX, CSV) or browser CSV export for testing the import:
  values masked, titles, e-mail addresses, URLs and relying parties
  replaced by unique stand-ins, attachments zeroed, private keys emptied;
  ids, types, labels and timestamps kept.
